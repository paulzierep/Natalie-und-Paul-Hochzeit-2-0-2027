# Bergzeichnungen – alternative Entwürfe

Die Website verwendet wieder die ursprüngliche Bergzeichnung. Die Alternativen bleiben hier als Backup erhalten:

- **A:** `a-federzeichnung.svg` – feine Federzeichnung.
- **B:** `b-berggravur.svg` – detailliertere Berggravur.
- **C:** `c-alpenpanorama.svg` – Alpenpanorama mit Hütte und Tannen.

`index.html` zeigt alle drei Varianten auf Kraftpapier mit Namen und Datum. Zum Ansehen lokal im Browser öffnen. Diese Vorschau wird nicht über GitHub Pages veröffentlicht.

Alle Illustrationen sind originale SVG-Entwürfe, keine ortsgetreuen Darstellungen. Variante C bleibt zusätzlich unter `assets/alpenpanorama.svg` erhalten, wird aber auf der Startseite nicht eingebunden.
